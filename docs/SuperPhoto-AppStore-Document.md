## 三、描述（4000 字符内）

### 简体中文
```
相册整理王 是你的本地相册管家与私密空间，一站式搞定照片整理与隐私保护。

【批量整理，先入队后统一处理】
从桌面挑选一个相簿，一次最多整理一批照片。把不要的照片「下滑」加入本批待清理，任务结束再统一处理——不会立刻删除系统照片，给你反悔的余地；「上滑」把难决定的先延后，「右滑」把想留下的归入目标相簿，「左滑」把私密的送进保险箱，四个方向一次分完。

【私密保险箱，本地守护】
把不想被随手翻到的照片、实况与视频复制进 App 沙盒，由双盘密码（左盘 0–29、右盘 0–59，共 1800 种组合）守护。采用 PBKDF2-SHA256 本机派生密钥，内容默认只留在本机；VIP 可按需开启「iCloud 同步」，把标准档内容同步到你自己 Apple ID 的私有数据库，强加密内容与密码始终不上传。切到后台自动隐私遮罩，旁人瞄不到。

【目标收藏夹，右滑即归档】
整理前先在右侧滚轮选定一本相簿作为「目标收藏夹」，居中放大的那本就是当前目标。看到想留下的照片，右滑一下即飞入这本相簿。归档是移动而非复制——照片会从其它自建相簿中移出，始终只属于这一个目标，不会被重复归到多处。刚建好的空相簿也能直接设为目标，边整理边建档。

【整理统计】
记录每批整理进度与释放的空间，清理成果看得见。

【本地优先，隐私放心】
照片、保险箱副本、统计与偏好默认全部保存在本机；App 不向任何开发者服务器发起业务网络请求。唯一例外是你主动开启 VIP 的「iCloud 同步」（默认关闭）：标准档保险箱内容与元数据会同步到你自己 Apple ID 的 iCloud 私有数据库，用于跨设备访问，随时可以关闭；强加密档内容、密码与整理统计始终不上传。针对大屏与 iPhone Duo 双屏布局优化。

VIP 通过一次性购买永久解锁（非消耗型内购）：保险箱支持实况照片与视频、容量不限，解锁「本月」整理统计，并可选用「iCloud 同步」让标准档保险箱内容跨设备可用（默认关闭、可随时关闭）。付款一次即可永久使用，不会自动续订、也不会再次扣费，无需管理或取消订阅。更换设备或重装后，可在「设置 → VIP → 恢复购买」免费找回已购权益。购买与恢复均不影响你已保存的本地照片与保险箱数据。价格以 App Store 实际显示为准。

把杂乱交给相册整理王，把安心留给自己。
```

## 六、隐私营养标签（Privacy Nutrition）

- 数据收集：**不收集任何数据到开发者可控的服务**（App 不发起业务网络请求，不上传照片与元数据到任何服务器）。
- iCloud 同步（VIP 专属、默认关闭）：开启后，标准档保险箱内容与元数据存入**用户本人 Apple ID 的 CloudKit 私有数据库**，仅用于跨设备同步，开发者无法读取。若 ASC 隐私问卷要求披露，按「用户内容 → 其他用户内容 / 用于 App 功能 / 不与身份关联 / 不用于追踪」填写，并注明数据存储于用户自有 iCloud 账户；强加密档内容、密码、锁定状态与整理统计均不上传。
- 对应 App Store Connect「隐私」问卷填写要点：
  - 是否收集数据：不涉及开发者侧收集；iCloud 同步按上条披露
  - 是否关联用户身份：否
  - 是否用于追踪：否
- 内购说明：购买与恢复由系统 StoreKit / App Store 完成；App 仅读取「当前 Apple ID 是否持有该商品」用于解锁权益，不上传、不保存购买者身份或交易明细。
