## 一、技术基线

### 【已定】Q1 最低系统版本与设备范围

- 决策：**iOS 17+**（工程 target `17.6`），`TARGETED_DEVICE_FAMILY = "1,2"`（仅 iPhone + iPad）。
- 说明：工程当前 target 已是 17.6 与 `1,2`；项目级 `27.0` 与 `XROS_*` 需在 M0 清理，避免配置漂移。

### 【已定】Q2 是否支持 iPad / 横屏 / 折叠屏

- 决策：**A**，但扩展为"一套自适应布局"：
  - Compact 宽度（< 600pt）：iPhone 竖屏、**Duo 外屏**，使用边缘轨道 + 覆盖抽屉。
  - Regular 宽度（≥ 600pt）：**Duo 内屏**、iPad，左保险箱列 + 中舞台 + 右相簿列常驻三栏。
- 两种形态共用同一份视图与状态，仅布局容器切换；折叠/展开时保留当前照片、筛选与坞状态。

## 二、保险箱

### 【已定】Q3 入库时原件怎么处理

- 决策：**B** —— 复制原始资源到沙盒，再通过系统 API 删除原件（进"最近删除"30 天）。
- 影响：入库确认卡必须如实写明"原图会进入系统『最近删除』并保留 30 天"；取出时一律走 `PHAssetCreationRequest` 重建资产（因为原件已被删除），并恢复创建时间与相簿归属。
- 二期可增加 C（系统隐藏）作为"入库方式"选项，不作为一期默认。

### 【已定】Q4 保险箱文件是否排除 iCloud 备份

- 决策：**C** —— 一期 `isExcludedFromBackup = true`；二期提供"加密备份到 iCloud Drive"（用户主动触发，备份文件独立加密）。
- 后续更正（决策日志 #177）：二期未走 iCloud Drive 文件备份，改为 **CloudKit 私有数据库同步**（`iCloud.com.gpwzw.appSuperPhotos`，VIP 专属、默认关闭）。沙盒文件仍保持 `isExcludedFromBackup = true`，由 App 主动读取并作为 `CKAsset` 上传；强加密档因密钥不出本机被排除在同步之外，因此不需要为其再设计一套"独立加密备份格式"。

### 【已定】Q5 是否对保险箱文件做内容加密

- 决策：**A** —— 只用 iOS 数据保护（文件 `.completeFileProtection`），不做 App 层 AES-GCM。
- 影响：密码只保护"App 内访问"，不保护"被取证工具提取沙盒"；设置页文案不得宣称"加密存储"。二期做 iCloud 备份时再引入独立加密。

### 【已定】Q6 组合空间是否够用

- 决策：**A + C** —— 双盘统一 0–39，40 × 40 = 1600 种组合；阶梯锁定 + 随机组合生成器；二期 Face ID（密码仍为最终凭据）。

### 【已定】Q7 忘记密码怎么办

- 决策：**A** —— 不可找回；"重置保险箱"清空全部内容。重置前提示"原件已在系统『最近删除』中，请到照片 App 检查是否需要恢复"。

## 四、商业化

### 【已定】Q11 一期是否接入真实内购

- 决策：**不接内购，但先做完整的权益架构**：
  - 一期交付 `Entitlement` 判定层、`Feature` 门禁、容量与媒体类型校验；
  - 设置页提供"模拟 VIP"开关（仅用于测试，标注"模拟"）；
  - 二期用 StoreKit 2 接入订阅，替换模拟数据源。

### 【已定】Q12 免费/付费边界（含修正）

| 能力 | 免费 | VIP |
| --- | --- | --- |
| 壁炉 + 碎纸机 | 完整可用 | 完整可用 |
| 保险箱媒体类型 | **仅静态图片**（不含实况照片、视频） | 全部类型 |
| 保险箱容量 | 60 件且 ≤ 2GB | 不限（受设备空间限制） |
| 统计 | 今日 / 本周 / 累计总量 | 趋势图、方式分布、年度报告、分享图 |
| 密码盘皮肤 / 音效包 | 1 套基础 | 全部 |
| 更多销毁玩法 | 无 | 二期上线 |
| 批量上限 | 50 张/批 | 100 张/批 |
| Face ID 解锁 | 无 | 二期提供 |

- 硬规则不变：隐私与安全能力永不放付费墙；不限制"删除"本身；一期不出现购买按钮与价格。
- **2026-11-10 修正**（见 decision-log #146）：底部道具扩为五款（废纸篓 / 碎纸机 / 壁炉 / 邮筒 / 任意门），全部免费可切换；「五款道具各自的件数与占比」从 VIP 下放为免费（客观记录，不是分析报告），VIP 仍保留「本月周期」，趋势图 / 年度报告 / 分享图仍归二期。上表「壁炉 + 碎纸机」「方式分布」两行按此口径理解。
