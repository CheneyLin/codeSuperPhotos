# Photo Cleaner UI Kit

## Included
- `01_UI_Light/iPhone17ProMax_Light_1320x2868.png` — light-mode UI concept, 1320×2868 canvas
- `02_UI_Dark/iPhone17ProMax_Dark_1320x2868.png` — dark-mode UI concept, 1320×2868 canvas
- `03_Transparent_Assets/Icons/` — individually cropped RGBA PNG icon assets
- `04_Preview/Light_Dark_UI_and_Asset_Sheet.png` — original transparent combined concept sheet

## Design notes
- Visual direction: rounded 3D soft-neumorphism, cream/wood light theme and charcoal/navy dark theme.
- Main interaction: central photo card for swipe actions; right-side vertical album selector with front-facing folder icons and labels; no left/right navigation arrows.
- Top pegboard: key/lock entry and screwdriver/settings entry.
- Desk and under-desk trash area are included.

## Important production note
These are high-fidelity visual concept assets generated from a single rendered composition, not layered Figma/PSD source files. The two screen PNGs are fitted to a 1320×2868 transparent canvas for the iPhone 17 Pro Max target; the rendered mockup itself is not a native SwiftUI layout. Individual icon crops are RGBA PNGs from the generated sprite sheet. Please review crop edges and labels before shipping.
