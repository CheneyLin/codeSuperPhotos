# Photo Cleaner – Extra UI Assets

Asset set follows the established rounded 3D soft-plastic style.

## Contents
- `01_Icons`: finish/close and undo/back icons
- `02_Drop_Zones`: trash bin, paper shredder, fireplace
- `03_Safe`: safe artwork and lever in horizontal / 90-degree vertical orientations
- `04_Pixel_Display`: light and dark hanging pixel display panels
- `05_Favorites`: front-facing yellow default and blue selected folder/favorite tiles
- `Preview`: original generated asset sheet

## Target layout proportions
Percentages are intended relative to the app content width:
- Drop-zone objects: 50% width each (use as separate states/targets, not all side-by-side)
- Safe: 50% width
- Safe lever: 20% width
- Hanging pixel display: 60% width, 25:9 visual ratio
- Favorite folder: front-facing, centered artwork with clean face

## Notes
The PNGs are isolated from a rendered sprite sheet using foreground segmentation. Review fine edges and shadow transparency before production. These are visual PNG assets, not editable vector or 3D source files.
